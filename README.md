# Tischlerei Gruber – Homepage-Entwurf

Unverbindlicher Entwurf von Werner Hansmann für die Tischlerei Gruber GmbH, Niederwölz.
**Keine offizielle Seite der Firma.** Texte, Logo und Fotos gehören der Tischlerei Gruber bzw. den Fotografen.

## Ansehen

- Lokal: `index.html` im Browser öffnen (Doppelklick).
- Gesprächsunterlage: `vorher-nachher.html`.

## Aufbau

| Datei | Inhalt |
|---|---|
| `index.html` | Startseite |
| `leistungen.html` | Leistungen Büro & Objekt / Privat |
| `projekte.html` | 8 Referenzprojekte mit Fotos |
| `ueber-uns.html` | Familienbetrieb, Team, Werkstatt |
| `karriere.html` | Offene Stellen, Bewerbungsformular (Attrappe) |
| `kontakt.html` | Kontakt, Öffnungszeiten, Anfrageformular (Attrappe) |
| `impressum.html`, `datenschutz.html` | Rechtstexte (teilweise Platzhalter) |
| `stil.css` | Gestaltung |
| `assets/` | Logo und Fotos (aus tischlereigruber.at) |
| `fonts/` | Schrift „Outfit“ (SIL Open Font License), lokal eingebunden |

Reines HTML/CSS, kein Build-Schritt, keine externen Dienste, keine Cookies, keine Tracker.
Platzhalter für fehlende Angaben stehen in `[eckigen Klammern]` und sind braun markiert.

## Wichtig vor dem Veröffentlichen

- Das Repository **privat** anlegen. GitHub Pages macht eine Seite immer öffentlich – erst einschalten, wenn die Tischlerei Gruber zugestimmt hat und die Bildrechte geklärt sind (u. a. Fotos © Lukas Schaller).
- `noindex` in jeder Seite und `robots.txt` halten Suchmaschinen fern, solange es ein Entwurf ist. Für die echte Seite beides entfernen.
- Formulare senden nichts ab. Für den Live-Betrieb ein Formular-Backend ergänzen (z. B. in WordPress).
